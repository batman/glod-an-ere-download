# Glod an Ere

Ein Aufbauspiel in der Steinzeit: Führe ein Dorf auf einer Insel, lege Wege zwischen Fahnen an,
lass deine Leute die Waren tragen und sorge dafür, dass alle satt werden.

## Spielen (Windows, kostenlos)
1. [GlodAnEre-Setup.exe](https://github.com/batman/glod-an-ere-download/raw/main/GlodAnEre-Setup.exe) herunterladen.
2. Starten und installieren. Es braucht keine Administratorrechte.
3. Neue Versionen holt das Spiel selbst: im Hauptmenü auf „Nach Updates suchen“.

Das Spiel ist kostenlos. Es darf unverändert und kostenlos weitergegeben werden.
